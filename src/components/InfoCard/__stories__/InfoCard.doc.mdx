## Card heading and message

Set the card heading with the `label` prop.
Set the main card message with the `message` prop.

<Unstyled>
  <InfoCardAnotherText />
</Unstyled>
<br />

```tsx
import React from "react";
import { InfoCard } from "@dmitrygrigorov/components";

const Example: React.FC = () => (
  <InfoCard status="info" label="Heading" message="Different message text" />
);
```

## Customizing the buttons

Use `moreButtonText` and `collapseButtonText` to customize the controls that show and hide the detailed message.

<Unstyled>
  <InfoCardAnotherButtons />
</Unstyled>
<br />

```tsx
import React from "react";
import { InfoCard } from "@dmitrygrigorov/components";

const Example: React.FC = () => (
  <InfoCard
    status="info"
    label="Info Label"
    message="Detailed message text"
    moreButtonText="Show"
    collapseButtonText="Hide"
  />
);
```

## Closable `InfoCard`

Enable the close control with the `isClosableIcon` prop.

<Unstyled>
  <InfoCardClosable />
</Unstyled>
<br />

```tsx
import React from "react";
import { InfoCard } from "@dmitrygrigorov/components";

const Example: React.FC = () => (
  <InfoCard status="info" isClosableIcon={true} />
);
```

## Props

| Prop               | Type                                                  | Default   | Required | Description                                             |
| ------------------ | ----------------------------------------------------- | --------- | -------- | ------------------------------------------------------- |
| label              | `string`                                              | -         | ✓        | Heading text                                            |
| message            | `string`                                              | -         | -        | Detailed message text                                   |
| moreButtonText     | `string`                                              | Show more | -        | Label for the control that reveals the detailed message |
| collapseButtonText | `string`                                              | Collapse  | -        | Label for the control that hides the detailed message   |
| status             | `LabelStatus`                                         | `info`    | -        | Message status                                          |
| size               | `TInfoCardSize`                                       | `m`       | -        | Component size                                          |
| isClosableIcon     | `boolean`                                             | `false`   | -        | Adds a control for closing the component                |
| onCloseClick       | `(event: React.FormEvent<HTMLButtonElement>) => void` | -         | -        | Called when the close control is activated              |

:::

:::div
