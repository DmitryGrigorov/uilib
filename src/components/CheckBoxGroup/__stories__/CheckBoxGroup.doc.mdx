# CheckBoxGroup

A checkbox group is used when users can select multiple options from a list.
For a single option, use the standard [CheckBox](?path=/docs/components-protons-checkbox--demo) component.

## Content

Describe each checkbox in the `options` array. Every option can define its `label`, `value`, and whether it is interactive through `isDisabled`.

```tsx
import { useState } from "react";
import { CheckBoxGroup } from "@dmitrygrigorov/components";

const OPTIONS = [
  {
    label: "CheckBox 1",
    value: "one"
  },
  {
    label: "CheckBox 2",
    value: "two",
    isDisabled: true
  }
];

const Example = () => {
  const [value, setValue] = useState([]);

  return (
    <CheckBoxGroup
      options={OPTIONS}
      value={value}
      onChange={(event, _value) => setValue(_value)}
    />
  );
};
```

## Disabled checkboxes

Add `isDisabled` to disable the entire checkbox group.

```tsx

const OPTIONS = [
  {
    label: "CheckBox 1",
    value: "one"
  },
  {
    label: "CheckBox 2",
    value: "two",
    isDisabled: true
  }
];

const Example = () => {
  const [value, setValue] = useState([]);

  return (
    <CheckBoxGroup
      options={OPTIONS}
      value={value}
      onChange={(event, _value) => setValue(_value)}
      isDisabled
    />
  );
};
```

## Status

Use `status` to emphasize the group with `error`, `warning`, or `success` feedback.

### status="error"

```tsx
const OPTIONS = [
  {
    label: "CheckBox 1",
    value: "one"
  },
  {
    label: "CheckBox 2",
    value: "two",
    isDisabled: true
  }
];

<CheckBoxGroup
  value="one"
  status="error"
  statusText="error label"
  headerText="Error group"
  options={OPTIONS}
/>;
```

## Properties

| Parameter         | Type                                                                            | Default  | Required | Description                         |
| ----------------- | ------------------------------------------------------------------------------- | ------------ | -------------- | -------------------------------------- |
| options           | `ICheckGroupOption`                                                             | -        | ✓        | Checkbox options                    |
| value             | `(string,number)[]`                                                             | `-`      | ✓        | Selected values                     |
| isDisabled        | `boolean`                                                                       | -        | -        | Disables the checkbox group         |
| name              | `string`                                                                        | -        | -        | `<input>` name in the DOM           |
| onChange          | (\{event: ChangeEvent\<`HTMLInputElement`>, value: (string,number)[]}) => void; | -        | -        | Called when selected values change  |
| className         | `string`                                                                        | -        | -        | Additional CSS class                |
| direction         | `column, row`                                                                   | `column` | -        | Checkbox layout direction           |
| classNameCheckBox | `string`                                                                        | -        | -        | Additional checkbox CSS class       |
| status            | `default`, `error`, `warning`, `success`                                        | -        | -        | Status highlighting                 |
| statusText        | `string`                                                                        | -        | -        | Status text                         |
| headerText        | `string`                                                                        | -        | -        | Group heading text                  |

:::
:::div

### ICheckGroupOption

| Parameter  | Type                | Default | Required | Description       |
| ---------- | ------------------- | ------------ | -------------- | ----------------- |
| value      | `(string,number)[]` | -       | ✓        | Checkbox value    |
| isDisabled | `boolean`           | -       | -        | Disables checkbox |
| label      | `string`            | -       | ✓        | Checkbox text     |
