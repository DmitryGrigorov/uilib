## Usage

Pass an array of objects with `label`, `value`, and `isDisabled` properties to `options`. Each option's `value` must be unique.

```tsx
import { SegmentedControl } from "@dmitrygrigorov/components";

const Example = () => (
  <SegmentedControl
    options={[
      { label: "1", value: "1" },
      { label: "2", value: "2" },
      { label: "3", value: "3" }
    ]}
  />
);
```

## Setting a value

Pass the `value` property to set the selected value.

  <SegmentedControlDefaultValue2 />
</Unstyled>
<br />

```tsx
<SegmentedControl
  options={[

    { label: "2", value: "2" },
    { label: "3", value: "3" }
  ]}
  value="2"
/>
```

## Custom elements

To display custom content instead of plain text, pass a component as an option's `label`.

<Unstyled>
  <SegmentedControlLabelIcon />
</Unstyled>
<br />

```tsx
<SegmentedControl
  options={[
    { label: "1", value: "1" },
    { label: <IconSetting1 />, value: "2" },
    { label: "3", value: "3" }
  ]}
  value="2"
/>
```

## Changing the size

Pass `size` to change the component size.

<Unstyled>
  <SegmentedControlSizeS />
</Unstyled>
<br />

```tsx
<SegmentedControl
  options={[
    { label: "1", value: "1" },
    { label: <IconSetting1 />, value: "2" },
    { label: "3", value: "3" }
  ]}
  value="2"
  size="s"
/>
```

### TSegmentedControlSize

Available component sizes: `l`, `m`, `s`, `xs`.
:::

## Disabled options

Set an option's `isDisabled` property to disable it.

<Unstyled>
  <SegmentedControlOptionDisabled />
</Unstyled>
<br />

```tsx
<SegmentedControl
  options={[
    { label: "1", value: "1" },
    { label: "2", value: "2", isDisabled: true },
    { label: "3", value: "3" }
  ]}
/>
```

## Component props

| Property          | Type                    | Default | Required | Description                   |
| ----------------- | ----------------------- | ------- | -------- | ----------------------------- |
| className         | `string`                | -       | -        | Additional class              |
| onChange(`value`) | `void`                  | -       | -        | Called when the value changes |
| value             | `string, number`        | -       | -        | Selected value                |
| size              | `TSegmentedControlSize` | `l`     | -        | Component size                |
| options           | `Array<IOption>`        | -       | ✓        | Options to display            |

:::

:::div

## IOption

| Property   | Type                  | Default | Required | Description         |
| ---------- | --------------------- | ------- | -------- | ------------------- | --- |
| label      | `string, JSX.Element` | -       | ✓        | Option label        |
| value      | `string, number`      | -       | ✓        | Option value        |
| isDisabled | `boolean`             | -       | -        | Disables the option |     |

:::
