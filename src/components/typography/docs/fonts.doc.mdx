### H

#### Usage

```tsx
import React, { useState } from "react";
import { H } from "@dmitrygrigorov/components";

const Example: React.FC = () => {
  return (
    <H type="cancer" color="red">
       Text
    </H>
  );
};
```
<Unstyled>
<H type="cancer" color="red">Text</H>
</Unstyled>

#### Props

| Property   | Type                                                    | Default         | Required | Description                |
| ---------- | ------------------------------------------------------ | -------------------- | -------------- | ----------------------- |
| children   | `string`                                               | -                    | ✓              | Text                   |
| type       | `TFontType`                                            | -                    | -              | Text type              |
| fontFamily | `TFontFamily`                                          | -                    | -              | Font family                   |
| size       | `TSize`                                                | -                    | -              | Text size           |
| className  | `string`                                               | -                    | -              | Value of the `class` attribute |
| onClick    | `(event: React.MouseEvent<HTMLButtonElement>) => void` | -                    | -              | Click handler        |
| color      | `string`                                               | -                    | -              | Text color |
| as         | `TFontTag`                                             | `span`               | -              | HTML element to render |

##### TFontType

`aries` | `taurus` | `gemini` | `cancer` | `leo` | `virgo` | `libra` | `scorpius` | `capricornus` | `saggitarius`

##### TFontFamily

`Onest` | `Neue Machina`

##### TSize

`64` | `56` | `40` | `32` | `28` | `24` | `20` | `16`

##### TFontTag

`span` | `div` | `h1` | `h2` | `h3` | `h4` | `h5` | `h6`
