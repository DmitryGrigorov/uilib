# Critical Error

A critical-error page is shown when the user cannot access the application.

- [Description](#description)
- [Markup imports](#markup-imports)
- [Page markup](#page-markup)
- [Style imports](#style-imports)
- [Page styles](#page-styles)

## Description

This template contains a responsive application-error page. It has two main areas: a body with the error details and a footer with recovery actions. The footer can contain buttons, links, or supporting media. The layout adapts to the available viewport size.
