## Entering a number

Pass the number through `value` and handle changes with `onChange`.

```tsx
import { useState } from "react";
import { InputPhone } from "@dmitrygrigorov/components";

export const Example = () => {
  const [phone, setPhone] = useState<string>("null");

  const handleChange = (event, value) => setPhone(value);

  return <InputPhone value={phone} onChange={handleChange} />;
};
```

## Statuses

Use statuses to emphasize the field and communicate errors, warnings, or successful validation.
Set `status` to `default`, `error`, `warning`, or `success`. When omitted, the field uses its default appearance.

```tsx
<InputPhone status="error" />
<InputPhone status="warning" />
<InputPhone status="success" />
<InputPhone />
```

## Required fields

Set `isRequired` to make the field required. When a `placeholder` is present, an asterisk appears beside it.

```tsx
<InputPhone isRequired />
```

## Props

| Prop            | Type                                                                                                            | Default | Required | Description                                              |
| --------------- | --------------------------------------------------------------------------------------------------------------- | ------- | -------- | -------------------------------------------------------- |
| id              | `string`, `number`                                                                                              | -       | -        | Field ID in the DOM                                      |

| placeholder     | `string`, `[string, string]`                                                                                    | -       | -        | Hint displayed inside the field                          |
| isDisabled      | `boolean`                                                                                                       | `false` | -        | Disables the field                                       |
| onChange        | `onChange: (event: ChangeEvent<HTMLInputElement>`<br/> ` \ MouseEvent<HTMLDivElement>, value: string) => void;` | ✔      | -        | Called when the field value changes                      |
| onFocus         | `event: FocusEvent<HTMLInputElement>) => void`                                                                  | -       | -        | Called when the field receives focus                     |

| isReadOnly      | `boolean`                                                                                                       | -       | -        | Makes the field read-only                                |
