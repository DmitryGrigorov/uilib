# Scroll

The scrollbar shows the user's current position and provides quick navigation through a list.

## Import

```tsx
import { ScrollStyle } from "@dmitrygrigorov/components";
```

## Setup

Render the custom scrollbar styles at the root of your application.

```tsx
import { ScrollStyle } from "@dmitrygrigorov/components";

const App = () => (
  <div>
    <ScrollStyle />
  </div>
);
```
