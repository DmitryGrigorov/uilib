## Status

Statuses communicate different component states.

### Completed

Use `Completed` to indicate that an action has finished.

```tsx
<Status
  status="completed"
  leadIcon={<IconSetting1 />}
  trailIcon={<IconSetting1 />}>
  Label
</Status>
```

<Unstyled>
  <StatusCompleted />
</Unstyled>

### Processing

Use `Processing` to indicate that a request or action is in progress.

```tsx
<Status
  status="processing"
  leadIcon={<IconSetting1 />}
  trailIcon={<IconSetting1 />}>
  Label
</Status>
```

<Unstyled>
  <StatusProcessing />
</Unstyled>

### Error

Use `Error` to indicate a component error.

```tsx
<Status status="error" leadIcon={<IconSetting1 />} trailIcon={<IconSetting1 />}>
  Label
</Status>
```

<Unstyled>
  <StatusError />
</Unstyled>

### Success

Use `Success` to indicate that a request or action completed successfully.

```tsx
<Status
  status="success"
  leadIcon={<IconSetting1 />}
  trailIcon={<IconSetting1 />}>
  Label
</Status>
```

<Unstyled>
  <StatusSuccess />
</Unstyled>

### Warning

Use `Warning` to display a warning, for example when a password is weak.

```tsx
<Status
  status="warning"
  leadIcon={<IconSetting1 />}
  trailIcon={<IconSetting1 />}>
  Label
</Status>
```

<Unstyled>
  <StatusWarning />
</Unstyled>
<br />
<br />

### Status

Available values:
`completed`, `processing`, `error`, `success`, `warning`

## Using a color palette instead of a status

Use `colorType` instead of `status` to style the component with a named color palette.
Available colors: `blue`, `cyan`, `green`, `yellow`, `purple`, `teal`, `gray`, `midgrad`, `red`.

```tsx
export const StatusPurple: React.FC = () => (
  <Status colorType="purple">Label</Status>
);
```

<StatusPurple />
<br />
:::

## Disabled

Set `isDisabled` to disable the status. This property is available only with `isFilled`.

```tsx
<Status isFilled isDisabled>
  Label
</Status>
```

## Hover styles

Set `canHover` to enable hover styles. This property is available only with `isFilled`.

```tsx
<Status isFilled canHover>
  Label
</Status>
```

## Props

| Property   | Type                                                             | Default | Required | Description                                                                               |
| ---------- | ---------------------------------------------------------------- | ------- | -------- | ----------------------------------------------------------------------------------------- |
| children   | `string`                                                         | -       | ✓        | Label text                                                                                |
| className  | `string`                                                         | -       | -        | Additional class                                                                          |
| isFilled   | `boolean`                                                        | -       | -        | Fills the component background                                                            |
| status     | [`CompStatus`](#status)                                          | -       | -        | Component status style                                                                    |
| trailIcon  | `JSX.Element`                                                    | -       | -        |                                                                                           |
| icon       | `JSX.Element`                                                    | `false` | -        | Whether to show an icon; available for `info`, `error`, `success`, and `warning` statuses |
| as         | `React.ElementType`                                              | `p`     | -        | HTML element rendered in the DOM                                                          |
| colorType  | [`TColorTypeStatus`](#using-a-color-palette-instead-of-a-status) | `blue`  | -        | Component color palette                                                                   |
| isDisabled | `boolean`                                                        | -       | -        | Disables the component                                                                    |
| isPressed  | `boolean`                                                        | `false` | -        | Pressed state                                                                             |
| canHover   | `boolean`                                                        | -       | -        | Enables component hover styles                                                            |
