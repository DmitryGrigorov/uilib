## Description
The `convertStringToHexFormat` function converts a `string` value to `hex` format.


## Import

```tsx
import { convertStringToHexFormat } from "@dmitrygrigorov/components";
```

## Usage

```tsx
import { convertStringToHexFormat } from "@dmitrygrigorov/components";
  const colorInput = convertStringToHexFormat("#000000");
  // OUTPUT - #000000
```
