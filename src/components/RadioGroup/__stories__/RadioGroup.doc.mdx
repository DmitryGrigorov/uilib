## Content

Describe group items in `options`, or pass [RadioButton](?path=/docs/components-radiobutton--default) components as children. Each option accepts `value`, `label`, and optional `isDisabled`.

```tsx
const OPTIONS = [
  { value: "one", label: "one" },
  { value: "two", label: "two", isDisabled: true }
];

<RadioGroup value={null} options={OPTIONS} />;
```

```tsx
<RadioGroup value={null}>
  <RadioButton label="one" value="one" />
  <RadioButton label="two" value="two" isDisabled />
</RadioGroup>
```

:::

## Disabled option

Set `isDisabled` on an item in `options` to prevent that option from being selected.

```tsx
const OPTIONS = [
  { value: "one", label: "one" },
  { value: "two", label: "two", isDisabled: true },
  { value: "three", label: "three" }
];

<RadioGroup value="one" options={OPTIONS} />;
```

<Unstyled>
  <RadioGroupOptions />
</Unstyled>

## Disabled group

Set `isDisabled` to disable the entire group.

```tsx
const OPTIONS = [
  { value: "one", label: "one" },
  { value: "two", label: "two" },
  { value: "three", label: "three" }
];

<RadioGroup value="one" options={OPTIONS} isDisabled />;
```

## Status

Use `status` to emphasize the group with `error`, `warning`, or `success` styling.

```tsx

  { value: "one", label: "one" },

<RadioGroup
  value="one"
  status="error"
  statusText="error label"
```

## Props

| Property        | Type                                                          | Default | Required | Description                                         |
| --------------- | ------------------------------------------------------------- | ------- | -------- | --------------------------------------------------- |
| value           | `string, number`                                              | -       | -        | Value                                               |
| isDisabled      | `boolean`                                                     | -       | -        | Disables all radio buttons                          |
| name            | `string`                                                      | -       | -        | Accessible `<input>` name                           |
| onChange        | `(event: ChangeEvent<any>, value: string) => void; `          | -       | -        | Change callback                                     |
| onClick         | `(event: MouseEvent<HTMLDivElement>, value: string) => void;` | -       | -        | Click handler                                       |
| className       | `string`                                                      | -       | -        | Class name                                          |
| classNameButton | `string`                                                      | -       | -        | Class used to style `RadioButton` from `RadioGroup` |
| options         | `IRadioGroupOption[]`                                         | -       | -        | Radio-button data                                   |
| children        | `IRadioGroupOption[]`                                         | -       | -        | RadioButton children                                |
| status          | `default`, `error`, `warning`, `success`                      | -       | -        | Status styling                                      |
| statusText      | `string`                                                      | -       | -        | Status text                                         |
| headerText      | `string`                                                      | -       | -        | Group heading text                                  |

:::

:::div

### IRadioGroupOption

| Property   | Type                  | Default | Required | Description               |
| ---------- | --------------------- | ------- | -------- | ------------------------- |
| value      | `string, number`      | -       | -        | Value                     |
| isDisabled | `boolean`             | -       | -        | Disables the radio button |
| label      | `string, JSX.Element` | -       | -        | Button text               |
