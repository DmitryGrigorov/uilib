## Usage

Pass the required `title` property to define the accordion heading.

Place JSX inside `Accordion` to define the content that expands and collapses.

```tsx
const contentItem = (
  <List>
    <List.ListItem>Item 1</List.ListItem>
    <List.ListItem>Item 2</List.ListItem>
    <List.ListItem>Item 3</List.ListItem>
  </List>
);

const Example = () => {
  return (
    <Accordion title="Accordion" leadIcon={<IconMoreCircle />}>
      {contentItem}
    </Accordion>
  );
};
```

## Optional attributes

`Accordion` accepts the following optional properties:

- `isOpened` controls whether the accordion is expanded.
- `leadIcon` adds an icon before the title.
- `isDisabled` disables the accordion.

```tsx
const contentItem = (
  <div>
    <RadioButton label={"Radio 1"} />
    <RadioButton label={"Radio 2"} />
    <RadioButton label={"Radio 3"} isChecked />
    <Button>Button</Button>
  </div>
);

const Example = () => {
  return (
    <Accordion
      isOpened
      title="Accordion"
      leadIcon={<IconMoreCircle />}
      trailContent={<Tag title="18">18</Tag>}>
      {contentItem}
    </Accordion>
  );
};
```

## Properties

### Accordion properties

| Parameter      | Type                              | Default | Required | Description                                                                         |
| -------------- | --------------------------------- | ------------ | -------------- | --------------------------------------------------------------------------------- |
| title          | `string` \ `number`               | -       | ✓        | Heading text                                                                        |
| isDisabled     | `boolean`                         | -       | -        | Disables the element                                                                |
| isOpened       | `boolean`                         | -       | -        | Expands the accordion                                                               |
| className      | `string`                          | -       | -        | Additional class                                                                    |
| width          | `number` \ `string`               | -       | -        | Accordion width                                                                     |
| leadIcon       | `JSX.Element`                     | -       | -        | Icon displayed before the heading                                                   |
| trailContent   | `JSX.Element`                     | -       | -        | Additional content displayed to the right of the heading text                       |
| children       | `ReactNode`                       | -       | -        | Child components or elements                                                        |
| onToggle       | `(isOpen: boolean) => void;`      | -       | -        | Called when the open state changes                                                   |
