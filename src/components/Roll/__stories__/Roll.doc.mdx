# Roll

A navigation element for quickly switching between sections or panels. It contains `mainContent` and `rollContent`.
:::

## Import

```tsx
import { Roll } from "@dmitrygrigorov/components";
```

:::

:::div

## Heading

The component heading has two text areas on the left and trailing content on the right. Set the trailing content with `trailContentHeader`.

```tsx
<Roll
  titleHeader="Heading"
  subTitleHeader={23}
  trailContentHeader={<Button icon={<IconSetting1 />} size="s" />}
/>
```

<Unstyled>
  <HeaderRoll
    title="Heading"
    textOverflow="ellipsis"
    subTitle={23}
    trailContent={<Button icon={<IconSetting1 />} size="s" />}
  />
</Unstyled>

## Subheading

The subheading appears in `rollContent` and contains `titleSubHeader` plus the `labelSubHeader` status text.

```tsx
<Roll labelSubHeader="Hint" titleSubHeader="Subheading" isIconStatusSubHeader />
```

<Unstyled>
  <SubHeaderRoll
    title="Subheading"
    textOverflow="ellipsis"
    textLabel="Hint"
    style={{ padding: "16px" }}
    isIconLabel
  />
</Unstyled>
:::

:::div

## Switching content

`mainContent` is the primary content and `rollContent` is the secondary content. `isOpenRoll` controls which one is shown.
:::

:::div

## Footer

Roll can also render a footer, which appears together with `rollContent`.
:::

:::div

## Long text

Long headings are truncated with an ellipsis by default. Change the truncation behavior with `textOverflow`.

```tsx
<Roll
  titleHeader="Long text, very long text, very"
  subTitleHeader={23}
  trailContentHeader={<Button icon={<IconSetting1 />} size="s" />}
/>
```

## Usage

```tsx
import React, { useState } from "react";
import { Roll, Button } from "@dmitrygrigorov/components";

const RollExample: React.FC = () => {
  const [isOpenRoll, setIsOpenRoll] = useState(false);

  const handleClick = (): void => {
    setIsOpenRoll((prevState) => !prevState);
  };

  return (
    <Roll
      titleHeader="H-s"
      subTitleHeader="P2-l"
      mainContent={<MainContent />}
      rollContent={<RollContent />}
      titleSubHeader="P1-s"
      statusSubHeader="info"
      labelSubHeader="Focused label"
      isIconStatusSubHeader
      footer={<Footer />}
      isOpenRoll={isOpenRoll}
      trailContentHeader={
        <Button icon={<IconSetting1 />} size="s" onClick={handleClick} />
      }
    />
  );
};
```

## Props

| Property              | Type               | Default    | Required | Description                     |
| --------------------- | ------------------ | ---------- | -------- | ------------------------------- |
| style                 | `CSSProperties`    | -          | -        | Additional styles               |
| titleHeader           | `string`           | -          | ✔       | Heading text                    |
| subTitleHeader        | `string`           | -          | -        | Supporting heading text         |
| titleSubHeader        | `string`           | -          | -        | Subheading text                 |
| size                  | `l`, `m`           | `l`        | -        | Component size                  |
| textOverflow          | `clip`, `ellipsis` | `ellipsis` | -        | Long-text truncation method     |
| statusSubHeader       | `LabelStatus`      | -          | -        | Subheading status               |
| labelSubHeader        | `string`           | -          | -        | Subheading status text          |
| isOpenRoll            | `boolean`          | -          | -        | Whether Roll is open            |
| isIconStatusSubHeader | `boolean`          | -          | -        | Whether to show the status icon |
| mainContent           | `ReactElement`     | -          | ✔       | Primary content                 |
| rollContent           | `ReactElement`     | -          | ✔       | Secondary content               |
| footer                | `ReactElement`     | -          | -        | Footer content                  |
| className             | `string`           | -          | -        | Additional CSS class            |
| classNameContent      | `string`           | -          | -        | Additional content CSS class    |

:::

:::div

### LabelStatus

Available values:
`filled`, `info`, `focused`, `error`, `success`, `warning`
