# Icons

Install this package to use the icons.

## Installation

`npm i --save @dmitrygrigorov/icons-vue`

## Import

Import only the icons you need.

```
import { IconCloseCircle, IconCloseSquare ... } from "@dmitrygrigorov/icons-vue";
```

## Usage

```
<...>
<IconCloseCircle />
<IconCloseSquare />
<IconCloudImport />
<...>
```
