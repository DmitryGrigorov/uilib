# Pinning rows

Pinned rows appear above regular rows.

Pass `isPinningRows` to enable row pinning.

## Pin rows programmatically

To pin rows initially, pass data with the same shape as `rowData` to `pinnedRowData`. Use the [`setPinnedRowData` API](?path=/docs/tables-table-api--documentation) to update or add pinned rows at runtime.

```tsx
export const PinnedRowsTable: React.FC = () => {
  const columns = useMemo(
    () => [
      {
        field: "postId"
      },
      {
        field: "id"
      },
      {
        field: "name"
      },
      {
        field: "email"
      }
    ],
    []
  );

  const [comments, setComments] = useState<any[]>([]);

  const loadData = async (): Promise<void> => {
    const response = await fetch(
      "https://jsonplaceholder.typicode.com/comments"
    );
    const data = (await response.json()) as any[];
    setComments(data);
  };

  useEffect(() => {
    loadData();
  }, []);

  return (
    <Table
      paginationPageSize={10}
      title="Title 1"
      isPagination
      isSearch
      positionSearch="footer"
      columns={columns}
      rowData={comments}
      size="m"
      isPinningRows
      pinnedRowData={[comments[0]]}
    />
  );
};
```

## User-controlled row pinning

Users can pin the rows they need. The `onChangePinnedRowData` callback can report all pinned row data whenever pinning changes.

## Unsupported operations

Pinned rows are separate from the main dataset, so the following operations are unavailable:

- Sorting: pinned rows do not participate in sorting.
- Filtering: pinned rows cannot be filtered.

## Properties

### Table

| Property              | Type                      | Description                    |
| --------------------- | ------------------------- | ------------------------------ |
| isPinningRows         | `boolean`                 | Enables row pinning            |
| pinnedRowData         | `TData[] `                | Data displayed as pinned rows  |
| onChangePinnedRowData | `(rows: TData[]) => void` | Called when pinned rows change |

### API

| Property          | Type                                              | Description                                                                 |
| ----------------- | ------------------------------------------------- | --------------------------------------------------------------------------- |
| setPinnedRowData  | `(rows?: TData[])`                                | Sets pinned row data; calling it without an argument clears all pinned rows |
| getPinnedRowCount | `() => number`                                    | Returns the number of pinned rows                                           |
| getPinnedRow      | `(index: number) => IRowNode<TData> \/ undefined` | Returns a pinned row by index                                               |
