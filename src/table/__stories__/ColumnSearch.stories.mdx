# Column search

In addition to [global search](?path=/docs/tables-global-table-search--documentation), you can search within a specific column.

To add column search, set `isSearch` on the relevant entry in `columns`.

```tsx
const columns: TColumn[] = useMemo(
  () => [
    {
      field: "id"
    },
    {
      field: "name",
      isSearch: true
    },
    {
      field: "username"
    },
    {
      field: "email"
    },
    {
      field: "address.city",
      title: "city"
    }
  ],
  []
);
```

By default, the component performs the search locally. For server-side search, set `rowModel="server"` and use the `onSearch` handler. The handler supports both global and column search; for column search, its arguments include the active column data as well as the search query.

```tsx
type onSearch = (params: ITableSearchParams<TData, TValue>) => void;

export interface ITableSearchParams {
  value: string;
  field?: string;
}
```

```tsx
export const TableColumnSearch: React.FC<Partial<ITableProps>> = (props) => {
  const columns: TColumn[] = useMemo(
    () => [
      {
        field: "id"
      },
      {
        field: "name",
        isSearch: true
      },
      {
        field: "username"
      },
      {
        field: "email"
      },
      {
        field: "address.city",
        title: "city"
      }
    ],
    []
  );

  const [comments, setComments] = useState<any[]>([]);

  const loadData = async (): Promise<void> => {
    const response = await fetch("https://jsonplaceholder.typicode.com/users");
    const data = (await response.json()) as any[];
    setComments(data);
  };

  useEffect(() => {
    loadData();
  }, []);

  return (
    <Table {...props} columns={columns} rowData={comments} size="s" isSearch />
  );
};
```
