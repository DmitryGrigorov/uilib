# Editing cells

Set `isEditable` in a column definition to enable editing for its cells.

```tsx
const columns = [
  {
    field: "name",
    isEditable: true
  }
];

<Table columns={columns} />;
```

When you use [cell types](?path=/docs/tables-cell-types--documentation), the table provides the corresponding editors.

```tsx
export const TableEditable: React.FC<Partial<ITableProps>> = (props) => {
  const columns = useMemo(
    () => [
      {
        field: "id"
      },
      {
        field: "name",
        isEditable: true
      },
      {
        field: "username"
      },
      {
        field: "email"
      },
      {
        field: "address.city",
        title: "city"
      }
    ],
    []
  );

  const [comments, setComments] = useState<any[]>([]);

  const loadData = async (): Promise<void> => {
    const response = await fetch("https://jsonplaceholder.typicode.com/users");
    const data = (await response.json()) as any[];
    setComments(data);
  };

  useEffect(() => {
    loadData();
  }, []);

  return <Table {...props} columns={columns} rowData={comments} size="s" />;
};
```

## Conditional editing

Pass a callback to `isEditable` to determine dynamically which cells can be edited.

Example: select the edit button to choose the editable row.

```tsx
export const TableConditionalEditable: React.FC<Partial<ITableProps>> = (
  props
) => {
  const [rowIndexEditable, setRowIndexEditable] = useState<number | null>(null);
  const columns = [
    const columns: TColumn[] = useMemo(
    () => [
      {
        field: "id"
      },
      {
        field: "name",
        columnTypes: "basic",
        isEditable: (params: IEditableCallbackParams<any, string>) =>
          params.node.rowIndex === rowIndexEditable
      },
      {
        field: "username"
      },
      {
        field: "email"
      },
      {
        field: "address.city",
        title: "city"
      },
      {
        field: "edit",
        cellRenderer: ({ rowIndex }) => (
          <Button
            viewType="icon"
            onClick={() => setRowIndexEditable(rowIndex)}
            size="s">
            <IconEdit2 />
          </Button>
        )
      }
    ],
    []
  );

  const [comments, setComments] = useState<any[]>([]);

  const loadData = async (): Promise<void> => {
    const response = await fetch("https://jsonplaceholder.typicode.com/users");
    const data = (await response.json()) as any[];
    setComments(data);
  };

  useEffect(() => {
    loadData();
  }, []);

  return <Table {...props} columns={columns} rowData={comments} size="s" />;
};
```

### ValueSetter

`valueSetter` is an alternative to the default update behavior, which writes through `field`. Use it when you need full control over updates, do not use `field`, or work with a data item that has a more complex structure than a simple key-value pair.

`valueSetter` complements `valueGetter`: `valueGetter` reads values through a function instead of a field, while `valueSetter` writes them through a function.

```tsx
const columns = useMemo(
  () => [
    {
      field: "name"
    },
    {
      valueGetter: (params) => {
        return params.data.name;
      },
      valueSetter: (params) => {
        params.data.name = params.newValue;
        return true;
      }
    }
  ],
  []
);
```

`valueSetter` must return `true` when the value was updated successfully and `false` otherwise. Returning `true` tells the table to refresh the data.

```ts
export interface IValueSetterParams<TData = any, TValue = any> {
  oldValue: TValue;
  newValue: TValue;
  rowNode: IRowNode<TData>;
  data: TData;
  column: TColumn<TData, TValue>;
}

export type TValueSetterFunc<TData = any, TValue = any> = (
  params: IValueSetterParams<TData, TValue>
) => boolean;
```

## Cell editors

A cell editor is the interface, usually rendered inside a cell, that handles the edit operation. The table provides standard editors based on the [cell type](?path=/docs/tables-cell-types--documentation), and you can also create custom editors.

Configure a cell editor with `cellEditor` in the column definition.

## Editing events

### onCellValueChanged — value changed after editing

```tsx
 onCellValueChanged?: (event: ICellValueChangedEvent<TData, TValue>) => void;

interface ICellValueChangedEvent<TData, TValue> {
  oldValue: TValue;
  newValue: TValue;
  column: TColumn<TData, TValue>;
  data: TData;
  node: IRowNode<TData>;
  rowIndex: number;
  event: Event;
}

```

### onCellEditingStarted — cell editing started

```tsx
 onCellEditingStarted?: (
    event: ICellEditingStartedEvent<TData, TValue>
  ) => void;

interface ICellEditingStartedEvent<TData, TValue> {
  column: TColumn<TData, TValue>;
  value: TValue;
  data: TData;
  node: IRowNode<TData>;
  rowIndex: number;
  event: Event;
}
```

### onCellEditingStopped — cell editing stopped

```tsx
 onCellEditingStopped?: (
    event: ICellEditingStoppedEvent<TData, TValue>
  ) => void;

interface ICellEditingStoppedEvent<TData, TValue> {
  oldValue: TValue;
  newValue: TValue;
  column: TColumn<TData, TValue>;
  data: TData;
  node: IRowNode<TData>;
  rowIndex: number;
  event: Event;
}
```

### onRowEditingStarted — row editing started

```tsx
 onRowEditingStarted?: (event: IRowEditingStartedEvent<TData>) => void;

interface IRowEditingStartedEvent<TData> {
  data: TData;
  node: IRowNode<TData>;
  rowIndex: number;
  event: Event;
}
```

### onRowEditingStopped — row editing stopped

```tsx
  onRowEditingStopped?: (event: IRowEditingStoppedEvent<TData>) => void;

interface IRowEditingStoppedEvent<TData> {
  data: TData;
  node: IRowNode<TData>;
  rowIndex: number;
  event: Event;
}
```
